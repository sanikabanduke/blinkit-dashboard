# blinkit-dashboard
An interactive Blinkit Sales Analysis Dashboard built using Microsoft Power BI to analyze sales performance, item types, outlet locations, fat content, and customer ratings. This project uses data visualization and interactive filters to present key business insights and support data-driven decision-making.

**Key Insights**

- Total sales reached 1.20M.
- Average sales: 140.99.
- Average customer rating: 3.92.
- Supermarket Type1 contributes the highest sales.
- Fruits and Vegetables and Snack Foods are leading sales categories.
- Tier 3 outlets generate the highest sales among location tiers.

**Features**

- Interactive slicers for outlet location, outlet size, and item type.
- KPI cards for key metrics.
- Sales analysis by item type and outlet type.
- Customer rating analysis by product category.
- Low-fat vs. regular-fat product distribution.
- Interactive Power BI visualizations for business insights.
